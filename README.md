# Блокировщик рекламы для Safari

Расширение для Safari (macOS, при желании и iPhone/iPad), которое:

- **блокирует рекламные сети** — Google Ads/DoubleClick, Яндекс Директ/РСЯ, AdFox, myTarget/VK, Taboola, Outbrain, MGID, СМИ2, Criteo и ещё ~120 доменов (`extension/rules/ads.json`);
- **прячет рекламные блоки** на страницах, даже если реклама подгрузилась с самого сайта (`extension/content/cosmetic.js`);
- **убирает рекламу в видео**: блокирует рекламные вставки VAST/VMAP и Google IMA в плеерах на сайтах, а на YouTube вырезает рекламу из ответа плеера; если ролик всё-таки начался — глушит звук, проматывает его и нажимает «Пропустить» (`extension/content/youtube*.js`);
- **глушит рекламу внутри любых видеоплееров** (онлайн-кинотеатры, плееры в iframe): ответы рекламных серверов в формате VAST/VMAP подменяются на «рекламы нет», с какого бы сервера они ни пришли (`extension/content/vast-guard.js`). Всплывающие видео-окна в углу страницы (videoroll и т.п.) убираются;
- **блокирует всплывающие окна и pop-under**: сети PopAds, PropellerAds, Adsterra, ExoClick и др. (`extension/rules/popups.json`) плюс защита от невидимых слоёв поверх видео, которые открывают рекламу при клике (`extension/content/popup-guard.js`);
- **защищает от «Отключите блокировщик рекламы»**: вместо рекламных скриптов Google, Яндекса, Google IMA и детекторов вроде FuckAdBlock сайт получает пустышки из `extension/stubs/`, поэтому проверка думает, что реклама загрузилась. Пустые блоки-приманки остаются на месте (просто невидимы), а окна с просьбой отключить блокировщик убираются, прокрутка страницы возвращается (`extension/content/anti-adblock.js`). На YouTube закрывается окно «Блокировщики рекламы нарушают правила»;
- **кнопка на панели Safari** позволяет выключить блокировку на конкретном сайте, если он сломался.

## Установка на Mac

Один раз подготовьте:

1. Установите **Xcode** из App Store (бесплатно), откройте его и примите лицензию.
2. В Xcode откройте **Settings (Cmd+,) → Accounts**, нажмите **«+» → Apple ID** и войдите своим Apple ID. Платный аккаунт разработчика не нужен.

Потом дважды кликните файл **«Собрать блокировщик.command»** в этой папке. Или выполните в Терминале:

```bash
cd ~/Projects/SafariAdBlocker && ./build.sh
```

Скрипт соберёт приложение, подпишет его вашим Apple ID, положит в «Программы» и запустит.

Если macOS скажет, что файл .command нельзя открыть, кликните по нему правой кнопкой → «Открыть» → «Открыть».

### Включение в Safari (один раз)

1. **Safari → Настройки → Расширения** — поставьте галочку «Блокировщик рекламы».
2. Там же нажмите **«Изменить сайты…»** и выберите **«Разрешить»** для всех сайтов. Без этого скрытие баннеров и защита на YouTube не работают.

Благодаря подписи Apple ID расширение остаётся включённым после перезапуска Safari и Mac. Галочка «Разрешать неподписанные расширения» не нужна.

Если блокировщик всё же пропал из Safari (например, после обновления macOS или Xcode), снова дважды кликните «Собрать блокировщик.command» — через минуту всё вернётся.

## Установка на iPhone/iPad

Создайте проект без флага `--macos-only` — появится ещё цель для iOS. Подключите iPhone, в Xcode выберите схему *AdBlocker (iOS)* и своё устройство, укажите Team и нажмите ▶︎. На телефоне: **Настройки → Приложения → Safari → Расширения → Блокировщик рекламы** → включить и разрешить на всех сайтах. С бесплатным Apple ID приложение работает 7 дней, потом его нужно установить заново из Xcode.

## Как пользоваться

Значок на панели Safari показывает текущий сайт и переключатель. Если сайт перестал работать (не открывается вход, не грузится плеер), выключите блокировку для него и обновите страницу.

## Изменение списков

Списки доменов лежат в `tools/build_rules.py`. Добавьте домен и выполните:

```bash
python3 tools/build_rules.py
```

Потом пересоберите приложение (`./build.sh` или ▶︎ в Xcode) и обновите страницу.

## Ограничения

- YouTube регулярно меняет способ показа рекламы. Если реклама снова появилась, обычно достаточно обновить селекторы в `content/youtube.js`.
- Защита от всплывающих окон блокирует окна на чужие сайты, открытые без клика по ссылке или кнопке. Если на каком-то сайте не открывается окно входа, выключите блокировщик на нём.
